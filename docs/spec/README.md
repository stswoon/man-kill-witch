# Man Kill Witch — спецификация

Спецификация фиксирует требования к поведению, арту и архитектуре. Это источник правды для
реализации и приёмки; `docs/plan/` ссылается на неё.

- Точные числа, формулы и структуры данных сверяются с кодом и тестами. Если спека и код
  расходятся, прав код, а спеку нужно синхронизировать.
- `docs/design.md` — человеческое описание дизайна и ощущения. Идентичность героя в нём
  обновлена сторей `S08`; физические числа — под HD-масштаб (×5) в `S13`.
- `docs/plan/README.md` — стори, статусы и фронт поставки.

## Принятые решения

| ID | Решение | Источник |
|---|---|---|
| D1 | Анимации персонажей и врагов переводятся на Phaser AnimationManager (`this.anims`). | Задача, п. 1 |
| D2 | Физика переводится на Phaser Arcade Physics. Фиксированный шаг **1/70 с** остаётся продуктовым требованием. | Задача, п. 1 |
| D3 | Весь видимый арт перерисовывается с нуля: герой, враги, тайлсет, титульный экран, HUD. Старые неиспользуемые файлы удаляются. HD-направление: арт — Full HD-иллюстрация, не пиксель-арт. | Задача, п. 3; HD-направление 2026-11-15 |
| D4 | Референс старого арта допустим только для пропорций и таймингов анимаций; новые силуэты и детали — собственные. Автоконвертация, трассировка и производные от оригинальных спрайтов запрещены. Палитра свободная. | Задача, п. 3; HD-направление 2026-11-15 |
| D5 | У героя новый облик, имя и предыстория. Название игры «Man Kill Witch» и `package.json name` не меняются. | Задача, п. 2 |
| D6 | Анимация — визуальный слой. Её фаза не входит в детерминированную симуляцию; игровые таймеры остаются тиковыми 1/70. | D1 + D2 |
| D7 | Рабочая концепция героя: **Сайлас Грив (Silas Grieve), «Могильщик»**. | `04-hero.md` |
| D8 | **Arcade Physics:** `web/src/game.ts` остаётся Phaser-free слоем правил; Arcade-мир и тела живут в `web/src/arcade/*`, владелец — `GameScene`; один шаг Arcade-мира на тик правил 1/70. | Q4 = A, `01-architecture.md` |
| D9 | **Дверь:** до открытия статичная дверь — тайлы уровня; открытие — спрайт `s_door.png` `160×240`, 3 кадра, `door-open`; `Game` отдаёт состояние, очищает 2×3 тайла, завершает уровень на 15-м тике. | Q5 = A, `02-gameplay.md` |
| D10 | **Тайлсет:** перерисовать на месте, та же сетка `32×27` и те же индексы; атлас `2560×2160` (ячейка `80×80`); уровни и `tileinfo.json` не меняются; арт для 501 используемого тайла, без ремапа. | Q6 = A, `03-art.md` |
| D11 | **Прохождение:** очки, оставшиеся жизни и `nextExtraLife` сохраняются между уровнями; game over/win/титул/отладочный запуск начинают новое прохождение. | Q7 = Б, `02-gameplay.md` |

**HD-направление (2026-11-15).** Рендер переведён на Full HD `1920×1080`, опорная сетка
`384×216` (×5), арт — HD-иллюстрация без пиксель-арта. Этим сняты EGA-требования D3/D4 и
прежние размеры D9/D10; новые значения — в `03-art.md`, `01-architecture.md` §1.1 и
`05-animation.md`. Запись журнала решений — `docs/plan/artifacts/decisions-S05.md` (D21);
новых D-номеров в этой таблице нет.

## Открытые вопросы

Открытых вопросов нет. Q4–Q7 закрыты решениями D8–D11; зависимые стори нарезаны в
`docs/plan/`.

HD-вопросы закрыты 2026-11-15: 16:9 принят как есть (уровни 04/08 не меняются); мир — в px
экрана, `TILE = 80`, `384×216` — опорная сетка (вариант A); временный арт пилота —
механические ×5-копии старого арта, финальные файлы — HD; S10–S12 переписаны in-place;
незакоммиченный EGA-арт S05/S07/S09 отброшен. Новых D-номеров в этой таблице нет.
