1) Игра должна быть на весь экран

2) Mobile First

3) Добавить интересные голосовые звуки, голос через elevenlabs api v4 (есть токен), например рычание зомби и ведьм,
   персонаж периодически что-нить рандомное говорит, например при поднятии ключей, убийство.

4) добавить историю и диалоги перед каждой миссией, в конце и в ключевых моментах игры

5) системы апгрейдов оружия (пули должны кончаться) + ближнее оружие нож + броня

6) Звук — новый. Скримы, открывание двери, выстрелы и многое другое

7) Уровни — новые, свои. Язык дизайна (какой прыжок проходим, где ставить секрет, ритм) копировать можно, карты — нет.

8) нужен 1-2-3 фоны, один двигается как параллакс, чтобы было более объемно

9) добавить двойной прыжок

10) видимость должна быть на весь экран, на широкоформатном экране сейчас есть черные полосы по бокам

11) много, где происходит проваливание сквозь текстуры. Сделай четкое разделение спрайтов, которые имеют коллизии, и
    которые - нет. Много каких-то полочек. Иногда нельзя пройти через полку снизу вверх, а сверху вниз проваливаешься.
    Также проваливаешься когда идешь по кирпичу. Где-то двери представляют собой не дверь а просто квадрат, когда
    открываешь видишь анимацию двери.

12) Монстры не должны быть мелкими ниже охотника - а то не понятно как по ним попасть

13) При стрельбе вверх пуля в виде тире горизонтальная, а должна быть по направлению полета

14) Шарф у охотника должен двигаться-анимироваться в стоячем положении, фонарь должен немного менять яркость, при
    изменении направления оружия - направление оружия должно меняться, чтобы было понятно куда полетит пуля, сейчас
    вообще ружье смотрит вниз, а стреляет вперед

15) нет меню при входе в игру

16) проверки в браузере запускай в headless режиме

17) в меню в setting - добавить выбор русского или английского языков, по умолчанию пока русский

18) Game Over нужно обернуть в попап + кнопка выхода в меню

19) в меню в setting - добавить громкость музыки и голоса

20) рисовать версию игры внизу слева в меню

21) кнопка выхода из игры + кнопка выхода в меню из уровня

22) если уровень пройден, то его можно выбрать при старте (его и первый не пройденный)
