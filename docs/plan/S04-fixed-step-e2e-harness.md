**Разблокирует:** S11 — регрессионная сетка для Arcade Physics.

## Цель

Получить браузерный тест, который прокручивает симуляцию ровно на `n` тиков `1/70` и
проверяет прыжок, скорость, приземление и повторяемость без зависимости от fps рендера.

## В scope

- `web/src/scenes/game-scene.ts`: добавить в `window.mkw` метод
  `tick(count: number, dt = 1 / 70): void`:
  - вызывает `this.step(dt)` ровно `count` раз;
  - после каждого шага вызывает `this.controls.endFrame()`, чтобы одиночные нажатия не
    «залипали» на все тики;
  - **это тестовое исключение**: обычный цикл делает `endFrame` и `view.render` один раз
    за рендер-кадр после серии фиксированных тиков; `mkw.tick` не рендерит каждый тик и не
    меняет обычный цикл.
- Новый `e2e/physics.spec.ts`:
  - прыжок с земли: подъём `40–50 px`, больше 2 тайлов и меньше 3;
  - повторный Space в воздухе не даёт второго прыжка;
  - разгон вправо до `vx = 132` за 10 тиков;
  - после приземления `onGround = true`, тело не проваливается в пол;
  - повторный запуск уровня и та же последовательность тиков дают те же `x/y` игрока.
- Обновить список отладочных методов в `AGENTS.md` (рядом с `mkw.step`).
