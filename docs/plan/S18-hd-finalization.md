# S18 — HD-финализация: доки, статус ассетов, сквозная приёмка

**Статус:** DONE

**Дорожка:** документация / приёмка.

**Параллель:** нет (финальная стори после всего HD-арта, Arcade и run state).

**Зависит от:** S10 (дверь), S11 (Arcade), S12 (run state), S14 (герой), S15 (враги),
S16 (тайлсет), S17 (HUD).

**Разблокирует:** нет.

## Цель

Закрыть HD-миграцию: привести `AGENTS.md`, `README.md` и `docs/design.md` в соответствие с
финальным HD-рендером, убрать статус «пиксель-арт/EGA», провести сквозную проверку всех
экранов и уровней.

## В scope

- `AGENTS.md`: описание проекта и правил — Full HD `1920×1080`, `TILE = 80`, опорная сетка
  `384×216`, HD-арт без пиксель-арта; структура и тесты соответствуют коду; `mkw` — как в
  `docs/spec/01-architecture.md` §6.
- `README.md`: раздел «Статус» — графика HD (не временная); уровни/звук остаются
  временными, если это так; структура соответствует коду.
- `docs/design.md`: финальные числа и ощущение, дверь, run state, оговорка про 16:9.
- Проверка, что в `AGENTS.md`, `README.md`, `docs/design.md` и `docs/spec/` нет устаревших
  требований `320×200`, `EGA`, ячейки `24×32`, «1 px / без сглаживания» (кроме исторических
  записей журнала `docs/plan/artifacts/**`).
- Сквозная приёмка в браузере: титул → Space → уровни 1–8 (цифры), дверь, HUD, анимации
  героя и всех вариантов врагов, game over/win; консоль чистая; кадры не «плывут»; швов
  тайлов и двери нет.
- Производительность: `1920×1080` WebGL держит 60 fps на десктопе; `build/` загружается без
  ошибок; размер ассетов приемлем.
- `npm test`, `npm run typecheck`, `npm run build`, `npm run test:e2e` зелёные.

## Вне scope

- Новые фичи, уровни, враги, звук, мобильная версия.
- Повторная перерисовка арта, если он уже принят S14–S17.
- HD-стилизация сообщений `GAME OVER`/`WIN` (остаются системным текстом) — отдельная задача.
- Новые тестовые раннеры, CI и зависимости.

## Приёмка

- `AGENTS.md`, `README.md`, `docs/design.md` соответствуют коду: разрешение, тайл, тела,
  скорости, HUD, дверь, run state.
- Нет устаревших EGA/`320×200`/`24×32`/«без сглаживания» требований вне журнала решений.
- Ручной сценарий: титул → Space → уровень 1; ходьба/прыжок/выстрел; дверь; уровни 1–8 по
  цифрам; смерть → GAME OVER → Space; победа на 8-м; консоль чистая.
- Все 8 уровней, титул и HUD выглядят целостно в HD; нет обрезки, швов и «плывущих»
  спрайтов.
- `npm test`, `npm run typecheck`, `npm run build`, `npm run test:e2e` проходят.
- В стори/PR — короткий отчёт с проверенными экранами и одной фразой о провенансе арта.

## Не делать

- Не менять механику, числа, уровни и ассеты без отдельной стори.
- Не добавлять CI, линтеры и зависимости.
- Не переписывать исторические записи `docs/plan/artifacts/**`.
