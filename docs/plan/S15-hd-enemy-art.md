# S15 — HD-арт врагов

**Статус:** OPEN

**Дорожка:** арт персонажей.

**Параллель:** S10, S14, S16, S17 — по файлам. Не параллелить: S13 (контракт кадров и
временные листы `s_chunk1/2.png`).

**Зависит от:** S13 (ячейка `120×160`, листы `840×800` / `600×800`, тест геометрии и
силуэтов).

**Разблокирует:** S18 (финальная приёмка).

## Цель

Заменить временные ×5-листы врагов на оригинальный HD-арт всех 11 визуальных вариантов,
сохранив группы кадров, индексы и поведение.

## В scope

- `web/public/assets/sprites/s_chunk1.png` — `840×800`, 35 кадров `120×160` (7 групп × 5).
- `web/public/assets/sprites/s_chunk2.png` — `600×800`, 25 ячеек: кадры 0–19 (4 группы × 5)
  + прозрачный паддинг 20–24.
- 11 групп: walker/charger/flyer-варианты; каждый `sprite` id — **новый собственный**
  силуэт, группы не повторяют друг друга и не заменяются одним рисунком.
- Стиль «мультяшный комикс» (`docs/spec/03-art.md`); палитра свободная, сглаживание
  разрешено; смотрят влево; прозрачный фон.
- Тело `60×60`: ноги/низ силуэта на нижней границе кадра; читаемость в движении.
- `tests/enemy-art.test.ts` — 35 и 20 каталогизированных кадров, паддинг `chunk2` 20–24,
  11 различных силуэтов (минимум два разных кадра в каждой группе); использует общий
  `tests/png.ts` (S13).

## Вне scope

- Герой (S14), тайлсет (S16), HUD (S17), дверь (S10), титул (S13).
- Код, `assets.ts`, `Enemy.sprite`, `SPRITE_BY_ID`, каталог анимаций — не меняются.
  Существующие тесты S13 не переписываются; добавляется `tests/enemy-art.test.ts`.
- Новые враги `spitter`/`witch` и их поведение.

## Папки (только эти)

```
web/public/assets/sprites/s_chunk1.png
web/public/assets/sprites/s_chunk2.png

```

## Публичный API

Не меняется: текстуры `chunk1`/`chunk2`, ячейка `120×160`, 35/20 каталогизированных кадров,
`Enemy.sprite` 2–12.

## Приёмка

- PNG `840×800` и `600×800`; 35 и 20 каталогизированных кадров; паддинг `chunk2` 20–24
  прозрачный; `tests/art-assets.test.ts` (S13) и `tests/enemy-art.test.ts` зелёные,
  11 силуэтов различны.
- Все визуальные варианты врагов играют свои анимации на уровнях; нет «дёрганья» при
  развороте; консоль чистая.
- В браузере проверены уровни с walker/charger/flyer; силуэты читаются на `1920×1080`.
- В стори/PR одна фраза о провенансе.

## Не делать

- Не менять число/порядок кадров и групп.
- Не рисовать всех врагов одним силуэтом.
- Не трогать код, существующие тесты и другие ассеты; исключение —
  `tests/enemy-art.test.ts` этой стори.
- Не добавлять EGA-палитру и пиксель-арт.
