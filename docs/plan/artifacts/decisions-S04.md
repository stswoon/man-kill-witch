# Решения S04 — 2026-11-14 23:05

## D13 — Заморозка Phaser-loop в e2e-стенде S04 (S04, этап Dev)

- Где: `docs/plan/S04-fixed-step-e2e-harness.md` (приёмка: «после `keyboard.press/down` симуляция продвигается только `mkw.tick`») / `e2e/physics.spec.ts` (`boot()`)
- Суть: при живом Phaser render-loop между `keyboard.press` и `mkw.tick` успевают пройти фоновые шаги симуляции, поэтому детерминизм «только `mkw.tick`» не гарантируется. Нужен способ остановить цикл в тесте.
- Решение: в `boot()` e2e после загрузки вызывать существующий отладочный `mkw.phaser.loop.sleep()` и только потом подавать ввод; production-код и публичный API не меняются. Источник: рекомендация агента (вариант 1).
- Альтернативы: Б) синтетические `KeyboardEvent` внутри одного синхронного `evaluate` без заморозки — не использует `page.keyboard` и расходится с формулировкой приёмки, хрупче; В) добавить production-метод паузы симуляции — расширение публичного API ради теста, вне scope.
- Расхождение со спекой: нет (S04 прямо вводит тестовое исключение `mkw.tick`; `mkw.phaser` уже публичный отладочный доступ).
- Затронуто: `e2e/physics.spec.ts`, `web/src/scenes/game-scene.ts` (только `mkw.tick`).

## D14 — Нормализация `count` в `mkw.tick` (S04, этап Dev)

- Где: `web/src/scenes/game-scene.ts` (`tick`), `docs/plan/S04-fixed-step-e2e-harness.md:20-26`
- Суть: контракт говорит «вызывает `step(dt)` ровно `count` раз», но не определяет дробные и отрицательные значения; наивный цикл `for (i < count)` для `2.5` дал бы 3 шага, для `-1` — 0.
- Решение: нормализовать `Math.max(0, Math.floor(count))`; для целых неотрицательных `count` контракт выполняется точно, некорректный ввод безопасно приводится к ближайшему допустимому. Источник: рекомендация агента.
- Альтернативы: Б) бросать исключение на нецелый/отрицательный `count` — строже, но ломает отладочный вызов без пользы для e2e; В) оставить наивный цикл — неявное округление вверх для дробных, хуже предсказуемость.
- Расхождение со спекой: нет (спека задаёт только целые `n`).
- Затронуто: `web/src/scenes/game-scene.ts`, `e2e/physics.spec.ts`.
