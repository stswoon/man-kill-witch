## Замечания

1. **[окружение, не дефект S04]** Первый независимый `--repeat-each=3` дал 4/18 падений на
   `boot()` (`waitForFunction` по `mkw`) с ошибкой страницы «tileinfo.json was not loaded».
   Это совпало с пересборкой общего `build/` параллельным стори: `tools/build.mjs` делает
   `rm -rf build/`, mtime `build/bundle.js` = 23:17:00 попал ровно в таймауты; на чистом
   прогоне при mtime 23:17:21 — 30/30. Рекомендация оркестратору: не запускать сборки/e2e
   разных стори одновременно на общем `build/`; изоляция сборки — вне scope S04.
2. **[info]** `tick(Infinity)` зациклится (`Math.floor(Infinity)` = Infinity); D14 покрывает
   только дробные/отрицательные. Метод отладочный, на приёмку не влияет.
3. **[info]** Комментарий `tick` говорит «exactly count», хотя D14 нормализует `count`; для
   контрактных целых ≥ 0 утверждение верно — косметика.
4. **[info]** Тест прыжка опирается на свободное пространство над стартовой площадкой
   уровня 1 (декоративные тайлы 29/42 без коллизий). При смене тайлсета/коллизий уровня 1 в
   S09/S11 ожидание 40–50 px нужно перепроверить — это штатная работа регрессионной сетки.
5. **[info]** Постоянного теста на нормализацию D14 нет; QA доказал её рантайм-пробой. Для
   отладочного метода допустимо.
