# Решения S10 — 2026-11-15

## D24 — Обновление `tests/animation-catalog.test.ts` вне папок S10 (S10, этап Dev)

- Где: `docs/plan/S10-door-sprite.md` («Папки (только эти)», `tests/animation-catalog.test.ts` не указан) / `web/src/animation-catalog.ts` (новый ключ `door-open`).
- Суть: каталог получил `door-open`; существующий тест проверяет точный список ключей и зацикленность всех анимаций (`repeat: -1`). Без правки тест становится красным, хотя поведение героя/врагов не меняется.
- Решение: разрешить правку `tests/animation-catalog.test.ts`: добавить `door-open` в ожидаемые ключи, исключить дверь из проверки зацикленности и добавить точный тест `door-open` (3 кадра, 14 fps, `repeat: 0`). Проверка зацикленности остальных анимаций не ослаблена. Источник: выбор оркестратора (техническая необходимость).
- Альтернативы: Б) оставить тест красным — недопустимо; В) не добавлять `door-open` в каталог — ломает фичу S10; Г) скрыть дверь от теста — маскирует контракт.
- Расхождение со спекой: нет (контракт `door-open` задан S10).
- Затронуто: `tests/animation-catalog.test.ts`.

## D25 — Детали `DoorView` и константы двери (S10, этап Dev)

- Где: `docs/plan/S10-door-sprite.md` («Публичный API», «view: глубина позади персонажей»); `web/src/assets.ts`, `web/src/view/door-view.ts`.
- Суть: стори не задаёт точную глубину, не перечисляет `DOOR_W/H` и не говорит, как часто вызывать `play("door-open")` при `repeat: 0`.
- Решение: глубина `5` (над tilemap `0`, под пулями `10`, врагами `11`, игроком `12`); добавить `DOOR_W = 160`, `DOOR_H = 240` (используются загрузчиком и `content.test.ts`); запускать `door-open` один раз на триггер и скрывать при `buildLevel`/завершении, чтобы `repeat: 0` не перезапускал кадр 0. Источник: рекомендация Dev + выбор оркестратора.
- Альтернативы: Б) глубина `1`/`9` — конфликт с пулями/фоном; В) хардкод `160×240` в загрузчике/тесте — дублирование; Г) `play` каждый кадр — риск сброса анимации в конце.
- Расхождение со спекой: нет (значения не заданы, поведение соответствует D9).
- Затронуто: `web/src/assets.ts`, `web/src/view/door-view.ts`, `web/src/scenes/boot-scene.ts`.
