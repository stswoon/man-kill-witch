# Решения S11 — 2026-11-15

## D27 — Технические детали Arcade-миграции (S11, этап Dev)

- Где: `docs/plan/S11-arcade-physics.md`, `web/src/sim-contract.ts`, `web/src/arcade/arcade-sim.ts`, `web/src/scenes/game-scene.ts`, `web/src/phaser-view.ts`, `tests/*`.
- Суть: стори задаёт архитектуру, но не фиксирует несколько технических деталей: где хранить числа физики, создавать ли HUD на титуле, как защититься от двойного урона, как не туннелировать сквозь тайл при 2600 px/s, нужна ли фабрика `TickCommands` в тестах.
- Решение: числа физики — в `sim-contract.ts` (единый источник для правил и Arcade, `AGENTS.md` обновлён); HUD не создаётся на титуле (`buildLevel(game, withHud=false)`, иначе панель S17 была бы поверх титула); `lives` не ниже 0, после `gameOver` касания игнорируются (защита от двойного урона в одном тике); flyer не сталкивается с тайлами (как раньше, поворот/смерть решают правила по `Level.blocks`); `TILE_BIAS = 80` для anti-tunneling при 2600 px/s (числа ощущения не меняются); отдельная фабрика `TickCommands` в тестах не нужна — единственный источник команд `Game.update`, тесты проверяют их напрямую. Источник: рекомендации Dev + выбор оркестратора.
- Альтернативы: Б) числа в `game.ts` — дублирование с Arcade; В) HUD на титуле — визуальный дефект; Г) без clamp `lives`/игнора урона — двойной урон в одном тике; Д) без `TILE_BIAS` — туннелирование при максимальном падении; Е) мёртвая фабрика `TickCommands` — лишний код.
- Расхождение со спекой: нет (детали не заданы; числа соответствуют `02-gameplay.md`).
- Затронуто: `sim-contract.ts`, `arcade/arcade-sim.ts`, `game-scene.ts`, `phaser-view.ts`, `tests/helpers.ts`, `tests/game.test.ts`, `AGENTS.md`.

## D28 — Падение за карту: world bounds вместо телепорта (S11, этап Dev)

- Где: `docs/spec/02-gameplay.md` §3 (телепорт при падении ниже карты) / `web/src/arcade/arcade-sim.ts` (Arcade world bounds).
- Суть: Arcade-мир не даёт игроку и наземным врагам покинуть карту, поэтому документированный rules-телепорт «упал ниже карты → `y = 2*TILE`» стал недостижим. Спека и код расходятся.
- Решение: оставить Arcade world bounds; телепорт в правилах не возвращать. Синхронизацию `docs/spec/02-gameplay.md` §3 (удалить/переписать недостижимое правило) выполняет analyst в следующем планировочном проходе; в S11 код не меняется. Источник: ответ пользователя (2026-11-15).
- Альтернативы: Б) вернуть rules-фолбэк телепорта — сохраняет спеку, но добавляет мёртвый код и маскирует ошибки коллизий; В) оставить bounds и спеку без изменений — известное расхождение; отклонено.
- Расхождение со спекой: есть (`02-gameplay.md` §3), был вопрос пользователю; решение зафиксировано, текст спеки обновит analyst.
- Затронуто: `docs/spec/02-gameplay.md` (следующий planning), `arcade/arcade-sim.ts` (без изменений).
