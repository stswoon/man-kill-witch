  (на запуск не влияло — Playwright не дошёл).

  `process.execPath` (`node node_modules/@playwright/test/cli.js test`) с `PW_PORT=4183`,

  Это подтверждает, что `PW_PORT`/`PW_OUTPUT`/`PW_WORKERS` в конфиге работают, а набор зелёный.
- Фикс (одна строка, Dev/оркестратор): `spawn(process.execPath, [require.resolve("@playwright/test/cli"), "test", ...args], {…})`
  либо `spawn(npx, args, { shell: true, … })`; печатать workers из CLI. Регрессия:
  `node tools/e2e.mjs --list` должен завершаться 0 (спавн без браузеров).
