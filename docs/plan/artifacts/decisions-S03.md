## D15 — «Без сглаживания» относится к PNG, а не к CSS-масштабу канваса (S03, этап Dev)

- Где: `docs/plan/S03-title-art.md` («В scope»: «Палитра EGA 16 цветов, 1 px, без сглаживания»; «Приёмка»: текст читается при 1× и 2×) / `web/src/main.ts`, `web/index.html`.
- Суть: PNG нарисован без сглаживания, но при CSS-растяжении канваса в браузере включается билинейная фильтрация (в проекте нет `image-rendering: pixelated`). Dev спросил, считается ли это нарушением пункта «без сглаживания».
- Решение: «без сглаживания» — требование к самому ассету: 1 px, EGA, без антиалиасинга при отрисовке и хранении. Поведение CSS-масштабирования канваса — существующее поведение всего рендера, вне scope S03; acceptance требует лишь читаемости текста при 1× и 2×, она подтверждена. Источник: выбор оркестратора (трактовка acceptance).
- Альтернативы: Б) добавить `image-rendering: pixelated` в CSS — меняет глобальный рендер и требует отдельной стори/решения, не входит в папки S03; В) считать 2× блокером S03 — потребовал бы правки кода вне scope и не следует из формулировки «читается».
- Расхождение со спекой: нет.
- Затронуто: `web/public/assets/title1.png`; код и CSS не меняются.

- Где: `docs/spec/03-art.md` (EGA, 1 px), `docs/spec/01-architecture.md` (320×200), решения D3/D4/D10; S03/S05/S07/S09.
