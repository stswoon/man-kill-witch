## Фронт поставки

Максимум при 4 слотах — **4**.

### Волны при 4 слотах

| Волна | Готовые стори | Ширина | Комментарий |
|---|---|---|---|
| 1 | S13 | **1** | Гейт: меняет `SCREEN_W/H`, `TILE`, `SPRITE_W/H`, контракт ассетов и перегенерирует временные ×5-файлы. |
| 2 | S10, S14, S15, S16 | **4** | S17 готов, но конфликтует с S10 по `assets.ts`/`boot-scene.ts`/`content.test.ts`; S11 ждёт S10; S12 ждёт S11. |
| 3 | S11, S17 | **2** | После S10 пути S11 и S17 расходятся. S12 ждёт S11. |
| 4 | S12 | **1** | Run state после Arcade. |
| 5 | S18 | **1** | Финальные доки и сквозная приёмка. |

**Максимальная ширина фронта: 4** (волна 2).

Критический путь: `S13 → S10 → S11 → S12 → S18` — 5 стори. Вторая ветка
`S13 → S16 → S18`: S16 (501 тайл `80×80`) — самая длинная арт-задача и может стать
фактическим критическим путём. S17 может стартовать сразу после S10, не дожидаясь S14–S16.

### Узкое место

1. **S13 — последовательный гейт.** Пока не заданы `TILE = 80`, `SCREEN 1920×1080`,
   кадр `120×160` и манифест, ни арт, ни код нельзя принять: старые ассеты не совпадут с
   загрузчиком и физикой. Поэтому волна 1 — ширина 1.
2. **`web/src/assets.ts` + `boot-scene.ts` + `content.test.ts`** — S13 → S10 → S17. S10
   (дверь) и S17 (HUD) не параллелятся: оба добавляют ключи и загрузку. S17 ждёт S10.
3. **`web/src/game.ts` + `game.test.ts`** — S13 → S10 → S11 → S12: самая длинная кодовая
   цепочка. S10 маленькая, но без неё S11 дважды переделывал бы дверной контракт.
4. **S16 (тайлсет)** — 501 тайл `80×80`, самый долгий арт. Он независим по файлам, но
   финальная приёмка S18 ждёт его.

### Почему шире не стало

- Волна 1: кроме S13 нечего запускать — все стори либо зависят от его констант, либо
  заменяют файлы, которые он перегенерирует.
- Волна 2 заполняет 4 слота. S17 не влезает из-за общих `assets.ts`/`boot-scene.ts`/
  `content.test.ts` с S10; S11 — из-за `game.ts` с S10; S12 — из-за S11.
- Дробление S17 на «арт» и «код» не расширяет фронт: код всё равно трогает `assets.ts` и
  `boot-scene.ts`, то есть тот же эксклюзив с S10.
- Дробление S16 на семьи тайлов не помогает: файл `tiles.png` один, а частичный атлас даёт
  чёрные тайлы на уровнях.
- S14 и S15 разделены по файлам (герой ∥ враги) — это и даёт четвёртый слот волны 2;
  дальнейшее дробление арта слотов не добавляет.
- S12 нельзя поднять раньше S11: оба меняют `game.ts`/`game-scene.ts`, run state пришлось бы
  встраивать в ещё не готовый Arcade-слой.
- S10 нельзя влить в S11: стори станет длиннее, критический путь не укоротится.
