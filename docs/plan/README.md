`CANCELLED`. Все стори ниже созданы в этом заходе; актуальные статусы — в таблице.
Открытых вопросов нет: Q4–Q7 закрыты решениями D8–D11.

## Фронт поставки

Максимум при 4 слотах — **4**.

### Волны при 4 слотах

| Волна | Готовые стори | Ширина | Комментарий |
|---|---|---|---|
| 1 | S01, S02, S03, S04 | **4** | S05, S08, S09 тоже готовы, но слоты заняты. |
| 2 | S05, S06, S07, S08 | **4** | S06/S07 ждут S01; S07 ещё ждёт S02. S09 ждёт слот. |
| 3 | S09, S10 | **2** | S10 ждёт S06/S07; S09 независима. S11 ждёт S10. |
| 4 | S11 | **1** | S10 и S11 сериализованы по `web/src/game.ts`. |
| 5 | S12 | **1** | S12 после S11: иначе run state раздувает S11 и промежуточные тесты. |

**Максимальная ширина фронта: 4** (волны 1 и 2).

Критический путь: `S02 → S07 → S10 → S11 → S12`; `S01 → S06 → S10 → S11 → S12`;
`S04/S08 → S11 → S12`. S09 — независимая арт-полоса.

### Узкое место

**S10 → S11 → S12** — жёсткая сериализация по `web/src/game.ts`, `game-scene.ts` и тестам.
S10 маленькая, но без неё S11 дважды переделывал бы дверной контракт. S11 — самая крупная
стори: меняет владельца физики, `game.ts`, `GameScene`, `view/characters`, тесты и
документацию. S12 вынесена после S11, чтобы не раздувать S11 семантикой прохождения; после
S11 промежуточное состояние с прежним сбросом очков остаётся зелёным.

Второе узкое место — **S09 (тайлсет)**: 501 тайл, самая длинная арт-задача. Она независима
и может идти параллельно S10/S11/S12, но не ускоряет код.

### Почему шире не стало

- Волны 1 и 2 заполняют 4 слота.
- В волне 3 независимы только S09 и S10; S11 ждёт S10 по `game.ts`. S10 и S11 нельзя
  параллелить: оба меняют дверной контракт и физику в одном файле.
- S11 нельзя дробить на «ядро физики» и «миграцию тестов»: половины не принимаются
  отдельно, промежуточное состояние не проходит `npm test`.
- S12 нельзя параллелить с S11: оба меняют `game.ts`/`game-scene.ts`; S12 после S11, иначе
  run state пришлось бы встраивать в ещё не готовый Arcade-слой.
- S05 уже разделена на арт (S05) и анимации (S06); дальнейшее дробление не даёт слотов.
- S09 — пятая готовая работа в волне 2, но 4 слота заняты S05–S08; она идёт в волне 3.
