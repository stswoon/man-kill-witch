# S23 — музыка и SFX: насыщенный WebAudio-синтез

**Статус:** OPEN

**Дорожка:** звук.

**Параллель:** S22 — по файлам (S22: арт, S23: `sfx.ts`, `music*`, `game-scene.ts`).
`AGENTS.md`/`README.md` — после S22, чтобы не конфликтовать в доках. Не параллелить с S19/S20
по `game-scene.ts` (они `DONE`).

**Зависит от:** S11/S12 (состояния `title / play / gameover / win`, вызовы `Sfx`), S18 (доки).

**Разблокирует:** голос/ElevenLabs и настройки громкости — отдельные стори.

## Цель

Заменить временные WebAudio-блипы на полноценный саундтрек и SFX по новым требованиям
`.opencode/agents/music-agent.md`: слоистые голоса, суб-бас, быстрые транзиенты, стерео,
короткий реверб/дилей; музыка по состояниям с lookahead-планированием и бесшовным циклом;
без аудиофайлов.

## В scope

- `web/src/sfx.ts`: переписать 7 эффектов (`shoot`, `hit`, `jump`, `pickup`, `die`, `door`,
  `win`) на слоистый синтез; публичный API сохранить.
- `web/src/music-catalog.ts`: чистые данные — BPM, таблицы нот, длины циклов, признак
  `loop`, треки `title`, `play`, `gameover`, `win`; без WebAudio и Phaser, тестируется в node.
- `web/src/music.ts`: планировщик по `ctx.currentTime` с lookahead, бесшовный цикл,
  мастер-гейн, стерео, дилей/реверб; ленивый `AudioContext` только после жеста.
- `web/src/scenes/game-scene.ts`: запуск, смена и остановка музыки по состояниям и событиям;
  вызовы `Sfx` остаются прежними.
- `tests/music.test.ts`: каталог — непустые треки, валидные ноты/частоты, BPM, длина цикла,
  уникальные ключи, `loop` у фоновых треков.
- `e2e/audio.spec.ts`: нет запросов `.mp3/.wav/.ogg`, консоль чистая, после Space контекст
  `running`, трек соответствует состоянию — через `mkw.audio`.
- `docs/design.md`: раздел звука — новые требования, треки, громкость.
- `AGENTS.md` и `README.md`: звук больше не «временный»; `music-catalog.ts`/`music.ts` в
  структуре.
- `work/s23-audio/**`: прототипы, превью, замеры; не коммитится.

## Публичный API

- `Sfx` — те же 7 методов и сигнатуры.
- `Music` — новый внутренний API: `setState("title" | "play" | "gameover" | "win")`,
  `stop()`; `AudioContext` создаётся лениво.
- `mkw.audio` — read-only диагностика `{ context, track }`; игровое состояние не меняет.

## Приёмка

- `npm test` (включая `tests/music.test.ts`), `npm run typecheck`, `npm run build` — зелёные.
- `npm run test:e2e` — зелёный; `e2e/audio.spec.ts` доказывает: аудиофайлов нет, ошибок нет,
  после жеста контекст `running`, трек соответствует состоянию.
- В браузере: титул — тема; Space — `play`; выстрел, попадание, прыжок, подбор, смерть,
  дверь и победа слышны и не превращаются в кашу; gameover/win меняют или останавливают
  музыку; рестарт снова даёт `play`.
- Нет автоплея до жеста, нет щелчков, осцилляторы останавливаются, 60 fps, консоль чистая,
  в Network нет аудиофайлов.
- Отчёт: BPM, состав голосов, таблицы нот, длина цикла, как проверено.
