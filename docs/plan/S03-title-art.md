# S03 — Новый титульный экран

**Статус:** DONE

**Дорожка:** арт / UI.

**Параллель:** S01, S02, S04 — по файлам. S06/S07 идут в следующей волне (зависят от S01), пересечения файлов с S03 нет.

**Зависит от:** нет (облик героя зафиксирован в `docs/spec/04-hero.md`).

**Разблокирует:** нет.

## Цель

Заменить титульный экран старой игры на оригинальный экран «Man Kill Witch» с новым
героем.

## В scope

- Новый `web/public/assets/title1.png`, `320×200`, непрозрачный PNG.
- Надпись ровно `MAN KILL WITCH`; никаких других названий, логотипов и копирайтов.
- Силуэт Сайласа Грива (широкополая шляпа, длинное пальто, дробовик) и мотив проклятого
  леса/ведьмы.
- Палитра EGA 16 цветов, 1 px, без сглаживания.
- Имя файла и ключ текстуры `title` не меняются.

## Вне scope

- Код, BootScene, HUD, спрайты героя/врагов, тайлсет.
- Анимированный титульный экран, дополнительные надписи, имя героя текстом.

## Папки (только эти)

```
web/public/assets/title1.png
```

## Публичный API

Не меняется: BootScene грузит `title1.png` как текстуру `title`, `320×200`.

## Приёмка

- PNG `320×200`; проверка по IHDR.
- В браузере на состоянии `title` виден новый экран; консоль чистая.
- Нет старых персонажей, текста `DANGEROUS DAVE`, `Softdisk`, `HAUNTED MANSION` и чужих
  логотипов.
- Текст `MAN KILL WITCH` читается при 1× и 2×.
- В стори/PR одна фраза о провенансе: нарисовано с нуля, без трассировки и автоконвертации.

## Не делать

- Не использовать старый `title1.png`/`title2.png` как основу, слой или источник пикселей.
- Не добавлять новые надписи и не менять название игры.
- Не трогать `BootScene`, HUD и `assets.ts`.
