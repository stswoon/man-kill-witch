# S05 — Новый арт героя и врагов

**Статус:** OPEN

**Дорожка:** арт персонажей.

**Параллель:** S06, S07, S08, S09 — по файлам. S05 пишет только PNG и с S11 по файлам не
конфликтует.
Пересечений с S06 нет: S06 читает те же листы, но не пишет их.

**Зависит от:** нет.

**Разблокирует:** нет (S06 может работать со старым артом; S05 нужен для финального вида).

## Цель

Заменить старый арт героя и всех визуальных вариантов врагов оригинальным, сохранив
раскладку кадров, чтобы старый тиковый view продолжал работать до S06.

## В scope

- `web/public/assets/sprites/s_hero.png` — `336×32` (14 кадров `24×32`): используются
  0 idle, 1–6 run, 13 jump; 7–12 — резерв. Герой смотрит **влево**, как старый арт.
  Новый облик — Сайлас Грив (`docs/spec/04-hero.md`).
- `web/public/assets/sprites/s_chunk1.png` — `168×160` (35 кадров `24×32`): 7 групп по 5.
- `web/public/assets/sprites/s_chunk2.png` — `120×160` (20 кадров `24×32`): 4 группы по 5.
- Все 11 визуальных вариантов врагов перерисовываются; группы и индексы — из
  `docs/spec/05-animation.md` (раздел 5).
- Арт оригинальный: без трассировки, автоконвертации, кропа и палитро-замены старых
  спрайтов. Палитра EGA разрешена.
- `tests/art-assets.test.ts` — точные размеры и число кадров `hero` / `chunk1` / `chunk2`.

## Вне scope

- Код, `game.ts`, `phaser-view.ts`, анимации, HUD, тайлсет, титульный экран, дверь.
- Изменение `SPRITE_NAMES`, имён текстур и структуры листов.
- Новые враги, spitter/witch.

web/public/assets/sprites/s_hero.png

tests/art-assets.test.ts

## Публичный API

Не меняется: текстуры `hero`, `chunk1`, `chunk2`; ячейка `24×32`; число кадров достаточно
для текущего view и каталога S06.

## Приёмка

- Размеры PNG: `s_hero.png` — `336×32`, `s_chunk1.png` — `168×160`, `s_chunk2.png` —
  `120×160`; ячейка `24×32`; кадров 14 / 35 / 20. Тест `art-assets` проверяет точные
  размеры и число кадров.
- Старый тиковый view до S06 работает: герой и враги смотрят влево, старая flip-логика
  (`facing > 0` / `dir > 0`) не меняется; idle/run/jump и группы врагов 2–12.
- Новые персонажи не похожи на старых; нет красной кепки/синего комбинезона; герой читается
  как Сайлас.
- Все 11 групп врагов имеют **новый собственный** силуэт; старые не копируются, нет копий
  одной группы.
- В браузере уровень 1 и титульный экран без ошибок; консоль чистая.
- В стори/PR одна фраза о провенансе: нарисовано с нуля, без трассировки и автоконвертации.

## Не делать

- Не менять имена файлов и текстур.
- Не заменять все группы врагов одним рисунком.
