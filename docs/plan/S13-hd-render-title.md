# S13 — Пилот: HD-рендер и HD-титульный экран

**Статус:** DONE

**Дорожка:** каркас / рендер / ассеты / тесты.

**Параллель:** нет. Не параллелить: S10–S12, S14–S17 — все зависят от глобальных
`SCREEN_W/H`, `TILE`, `SPRITE_W/H` и контракта ассетов; S13 к тому же перегенерирует
временные файлы, которые эти стори заменяют.

**Зависит от:** нет. База — `HEAD` (`3e760fe`); по решению 2026-11-15 незакоммиченный
EGA-арт и правки S05/S07/S09 отбрасываются и в HD-ветку не входят.

**Разблокирует:** S10, S11, S14, S15, S16, S17.

## Цель

Перевести рендер и логику на Full HD `1920×1080` с опорной сеткой `384×216` (×5) и
заменить титульный экран на HD-иллюстрацию, сохранив механику, фиксированный шаг `1/70` и
возможность играть все 8 уровней на временном арте.

## В scope

- `web/src/assets.ts`: `SCREEN_W = 1920`, `SCREEN_H = 1080`, `TILE = 80`,
  `SPRITE_W = 120`, `SPRITE_H = 160`; комментарий про опорную сетку `384×216` (1 единица =
  5 px).
- `web/src/game.ts` — только числа, без изменения правил:
  - физика: гравитация `4900`, бег `660`, ускорение `7000`, трение `9000`, прыжок `1500`,
    макс. падение `2600`;
  - тела: игрок `60×120`, враги `60×60`, пуля `15×10` (рисуется `15×5`);
  - скорости врагов: walker `130/150`, charger `200`, flyer `170`;
  - пуля: скорость `1900`, `vy = aim * 1900 * 0.75 = ±1425`, спавн `cx + facing*30`,
    `cy + aim*30`;
  - спавн игрока: `tx*80 + 10`, `ty*80 + 80 - 120`; respawn после урона — те же смещения;
    врагов: `tx*80 + 10`, `ty*80 + 20`;
  - flyer: амплитуда `120`, смерть при `y < 40` и `y > pixelHeight - 120`;
  - камера: `round(cx - 960)`, `round(cy - 540)`, зажим `0..pixelWidth - 1920`,
    `0..pixelHeight - 1080`;
  - `moveBody` шаг `40` (было 8); проба земли `+5` px (было +1);
  - таймеры (кулдаун 8, перезарядка 26, неуязвимость 30/60, жизнь пули 40) не меняются.
- `web/src/main.ts`: явный HD-рендер — `render: { antialias: true, pixelArt: false }`;
  размеры канваса берутся из `SCREEN_W/H`.
- `web/src/view/character-view.ts`: порог `abs(vx) > 40` (было 8); процедурная текстура пули
  `15×5`.
- `web/src/view/hud-view.ts`: временный системный HUD — шрифт `40px`, позиции и фон ×5;

- `web/src/view/message-view.ts`: временные размеры сообщений `80px` / `40px`, отступы ×5.
- **Границы пилота:** единственная новая отрисовка — HD-титул (дизайнер). HD-спрайты, тайлы,

## Публичный API

- `TILE = 80`, `SCREEN_W = 1920`, `SCREEN_H = 1080`, `SPRITE_W = 120`, `SPRITE_H = 160`.
- `Level.pixelWidth/pixelHeight` — в px экрана; JSON уровней не меняется.
- Ключи текстур прежние (`tiles`, `title`, `hero`, `chunk1`, `chunk2`); кадр спрайта
  `120×160`, титул `1920×1080`.
- `mkw` не меняется; позиции/размеры — в px экрана.
- Числа `game.ts` — ×5; правила и таймеры прежние.

## Приёмка

- Boot на `1920×1080`: canvas backing `1920×1080`, CSS сохраняет 16:9 и вписывается в окно;
  консоль чистая, ошибок загрузки нет.
- Титул `1920×1080`: HD-иллюстрация в стиле «мультяшный комикс», основная надпись
  `MAN KILL WITCH` читается, меню/кнопок/служебных надписей нет; Space/Enter → `play`,
  `mkw.getState()` меняется.
- Логика `384×216`: `SCREEN_W/5 = 384`, `SCREEN_H/5 = 216`, `TILE/5 = 16`;
  `TILE = 80`, видно `24×13.5` тайла; камера следует и зажимается; все 8 уровней
  загружаются и рисуются, чёрных/отсутствующих тайлов нет; уровни 04 и 08 шириной 24 тайла
  не имеют горизонтальной прокрутки (ожидаемо).
- Шаг `1/70` и аккумулятор не изменены; `mkw.tick(n)` детерминирован; прыжок перекрывает
  2 тайла и не достаёт 3 (подъём 200–250 px); бег `660`; пуля `1900`; смерть/дверь/уровни
  работают как раньше.
- Временный арт — ×5-копии старого, визуально пиксельные; это допустимо только в пилоте.
  Файлы коммитятся как временные и перезаписываются HD-артом в S14–S16.
- `npm test`, `npm run typecheck`, `npm run build`, `npm run test:e2e` зелёные.
- Новых runtime-зависимостей нет; `game.ts` по-прежнему без Phaser; tilemap не
  пересобирается каждый кадр.
- В стори/PR одна фраза о провенансе титула.
