# S09 — Новый тайлсет на месте

**Статус:** OPEN

**Дорожка:** арт среды.

**Параллель:** S05, S06, S07, S08, S10, S11, S12 — по файлам (`tiles.png` не трогают).

**Зависит от:** нет (D10).

**Разблокирует:** нет.

## Цель

Перерисовать тайлсет с нуля, сохранив сетку и индексы, чтобы уровни и `tileinfo.json`
остались нетронутыми.

## В scope

- `web/public/assets/tiles.png` — `512×432`, ячейка `16×16`, те же индексы.
- Нарисовать все **501** используемых уровнями индекса (348 проходимых декораций, 75
  потолков, 60 твёрдых, 18 behavior). Неиспользуемые ячейки можно оставить пустыми.
- Сохранить визуальные роли и коллизии каждого индекса; статичные дверные индексы из
  `docs/spec/02-gameplay.md` входят в 501 и обязательны.
- Оригинальный арт: EGA, 1 px, без сглаживания, трассировки и автоконвертации.

## Вне scope

- Уровни, `tileinfo.json`, загрузчик, код, тесты.
- Ремап индексов, новая раскладка уровней.
- Спрайты персонажей, HUD, титульный экран, дверной спрайт открытия.

## Папки (только эти)

```
web/public/assets/tiles.png
```

## Публичный API

Не меняется: текстура `tiles`, размер `512×432`, ячейка `16×16`, те же индексы.

## Приёмка

- PNG `512×432`; `tests/content.test.ts` проходит без изменений.
- Все 8 уровней рисуются без чёрных/отсутствующих тайлов; статичные двери выглядят
  целостно.
- Верхние поверхности, односторонние платформы и стены читаются; края без швов.
- Нет старых тайлов, трассировки и автоконвертации; в стори/PR одна фраза о провенансе.
- Ручная проверка всех 8 уровней в браузере; консоль чистая.

## Не делать

- Не менять `tileinfo.json`, `levels/*.json`, код и тесты.
- Не менять количество/порядок индексов и сетку.
- Не рисовать статичные двери спрайтом вместо тайлов.
