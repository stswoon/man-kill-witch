# S17 — HD-HUD: панель и bitmap-шрифт

**Статус:** DONE

**Дорожка:** HUD / UI.

**Параллель:** S11, S14, S15, S16 — по файлам. Не параллелить: S10 (`assets.ts`,
`boot-scene.ts`, `content.test.ts`).

**Зависит от:** S13 (манифест, загрузчик, `TILE = 80`, временный системный HUD).

**Разблокирует:** S18 (финальная приёмка).

## Цель

Заменить временный системный текст HUD на оригинальную HD-панель и bitmap-шрифт, сохранив
состав, смысл и расположение строк.

## В scope

- `web/public/assets/hud.png` — оригинальная панель `680×120` (136×24 ×5), HD-стиль,
  железная/костяная окантовка, один тёплый акцент (рисует `ui-designer-agent`).
- `web/public/assets/fonts/hud.png` + `hud.xml` — оригинальный моноширинный bitmap-шрифт
  (рисует `ui-designer-agent`): глифы `A–Z`, `0–9`, пробел, `/`; ячейка `25×35`,
  `xadvance = 30`, `lineHeight = 40`.
- `web/src/assets.ts`: `HUD_TEXTURE = "hud"`, `HUD_FONT = "hud-font"`.
- `web/src/scenes/boot-scene.ts`: `load.image(HUD_TEXTURE, ...)`,
  `load.bitmapFont(HUD_FONT, png, xml)`.
- `web/src/view/hud-view.ts`: панель `(0,0)` + `BitmapText`; те же строки:
  - `LVL {n}/8   LIVES {lives}`
  - `AMMO {ammo}   SCORE {score}`
  Позиции: панель `(0,0)`, строки `(20,15)` и `(20,65)` (4×5 и 13×5), `scrollFactor(0)`,
  глубины панель 100 / текст 101. Временный системный HUD и его масштабирование удаляются.
- `tests/content.test.ts`: манифест; размер панели `680×120`; метрики шрифта (`lineHeight 40`,
  ячейка `25×35`, `xadvance 30`), обязательные глифы, границы глифов внутри атласа.

## Вне scope

- Изменение состава/смысла HUD, локализация, новые счётчики.
- Титульный экран, сообщения `GAME OVER`/`WIN`, спрайты, тайлсет, физика.
- Системный шрифт и `Phaser.GameObjects.Text` для HUD.

## Публичный API

Новые текстуры/ключи `hud`, `hud-font`; `SPRITE_NAMES` не меняется; строки HUD не меняются;
панель `680×120`, шрифт `25×35`.

## Приёмка

- В `play` видна HD-панель и bitmap-шрифт; значения обновляются на уровне, при выстреле,
  подборе и смерти.
- На `title` HUD не виден; на `gameover`/`win` остаётся как раньше.
- `npm test` (манифест, метрики, глифы), `npm run typecheck`, `npm run test:e2e` проходят;
  консоль чистая.
- Ручная проверка: все строки читаемы на `1920×1080`, не выходят за панель, нет обрезки
  глифов; панель не спорит с героем.
- В стори/PR одна фраза о провенансе шрифта и панели.
- Провенанс: панель `hud.png` и шрифт `fonts/hud.png` + `hud.xml` нарисованы `ui-designer-agent` с нуля по авторским векторным путям, без установленных шрифтов, конвертации, трассировки и стороннего арта.
