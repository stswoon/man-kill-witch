# Man Kill Witch — дизайн

## Идентичность

Ретро-платформер с видом сбоку. **Сайлас Грив**, по прозвищу **«Могильщик»**, — пономарь и
могильщик деревни Холлоумир на краю проклятого леса. Ведьма не трогала его семью: она
украла **имена с надгробий**, и мёртвые поднялись безымянными. Деревенский совет выдал
последние освящённые патроны и долговую расписку, а Сайлас взял лопату и дробовик, чтобы
**закопать ведьму по всем правилам**. Он не избранный герой и не блещет харизмой: он
единственный, кто ещё помнит, как копать могилу и как уложить в неё то, что оттуда вылезло.
На нечисть он смотрит как на нерадивых клиентов — с усталой профессиональной досадой.

Мир — готическая сказка: тёмный лес → болото → избушка на курьих ножках → склеп → тронный
зал ведьмы. Тон — мрачная сказка с чёрным юмором, без хоррора-насилия.

- Логика с фиксированным шагом **1/70 с**.
- Движок — Phaser 4: сцены, загрузчик, tilemap, камера, рендер и Arcade Physics (S11, D8);
  ввод и звук — собственные.
- Рендер — Full HD `1920×1080`, арт — HD-иллюстрация без пиксель-арта; тайл `80×80` px,
  опорная сетка `384×216`.
- Пустые ячейки карты не чёрные: под уровнем лежит слой бесшовного тумана
  (`BACKDROP_TILE = 11` в `web/src/assets.ts`), камера залита тем же цветом `#101c29`.
- Имя, предыстория и облик героя — [`docs/spec/04-hero.md`](spec/04-hero.md); арт-дирекшн —
  [`docs/spec/03-art.md`](spec/03-art.md).

## Ощущение: измеримые параметры

Значения ниже — продуктовые решения, а не выгрузка из чужого кода. Их можно и нужно
менять осознанно, сверяясь с таблицей. Рендер — Full HD `1920×1080`, тайл `80×80` px
(опорная сетка `384×216`), поэтому все прежние пиксельные значения умножены на 5; шаг
`1/70` не менялся. Ощущение в тайлах и секундах сохраняется: бег — те же 8.25 тайла/с,
прыжок — те же ~2.7 тайла (219 px при шаге `1/70`).

| Параметр | Значение | В тайлах / секундах |
|---|---|---|
| Гравитация | 4900 px/s² | — |
| Скорость бега | 660 px/s | 8.25 тайла/с |
| Ускорение | 7000 px/s² | разгон до максимума ~0.09 с |
| Трение | 9000 px/s² | остановка ~0.07 с |
| Импульс прыжка | 1500 px/s | подъём 219 px ≈ **2.7 тайла**, вверх ~0.31 с |
| Макс. скорость падения | 2600 px/s | — |
| Размер героя | 60×120 px | 0.75×1.5 тайла |
| Скорость пули | 1900 px/s | — |
| Жизнь пули | 40 тиков | ~0.57 с ≈ 13.5 тайла |
| Задержка между выстрелами | 8 тиков | ~0.11 с |
| Перезарядка | 26 тиков | ~0.37 с, только стоя |

Прыжок должен перекрывать проём в 2 тайла с запасом и не доставать до платформы в 3 тайла
без разбега — это главный ориентир при правке физики.

Экран 16:9 (`24×13.5` тайла) показывает больше, чем прежние `20×12.5`: на уровнях 04 и 08
шириной ровно 24 тайла горизонтальной прокрутки нет. Принято 2026-11-15: 16:9 сохраняется,
уровни 04/08 не меняются; это новое штатное поведение. Канвас — `1920×1080` без `zoom`,
подгоняется CSS под окно с сохранением 16:9 (`web/src/main.ts`); внутри мира letterbox нет.

## Правила

- Прохождение (run): на старте 3 жизни, 0 очков, порог дополнительной жизни 5000. Очки,
  оставшиеся жизни и порог сохраняются между уровнями. Смерть внутри уровня отнимает жизнь,
  очки и порог сохраняются; респавн — на маркере спавна, при 0 жизней — game over.
- Враг: +100. Уровень пройден: +1000. Дополнительная жизнь каждые 5000.
- Дробовик: 8 патронов, перезарядка только когда герой стоит на земле и не стреляет.
- Прицел — три положения (вверх / прямо / вниз) на два направления взгляда: горизонтально
  `vx = ±1900`, при прицеле вверх/вниз ещё `vy = ±1425` (≈37°).
- Дверь — выход с уровня: до открытия это статичные тайлы уровня в блоке **2×3** (2 тайла
  по X, 3 по Y); при срабатывании открывается спрайт `s_door.png` (`160×240`, 3 кадра, D9),
  затем переход. Вход в дверь — **↑** (W) у двери: триггерная клетка на уровне центра героя
  или на клетку выше (арка на голову выше). Прыжок и простое касание дверь не открывают.
- Подборы: самоцветы (100/250/500), патроны (+1).
- Секреты: скрытые ниши за фальш-стенами, бонусные карманы над потолком.
- Новое прохождение (3 / 0 / 5000) начинают: титул, win (Space — уровень 1), game over
  (Space — текущий уровень), цифры 1–8 и `mkw.startLevel(n)`; `mkw.advanceLevel(n)` переходит
  на уровень с тем же прохождением (отладка и e2e).

## HUD

- Панель — `hud.png` `680×120` в левом верхнем углу (`scrollFactor(0)`), текст поверх
  bitmap-шрифтом `fonts/hud.png` + `hud.xml` (ячейка `25×35`, `xadvance = 30`,
  `lineHeight = 40`).
- Две строки: `LVL n/8   LIVES n` и `AMMO n   SCORE n`. Жизни и очки — из `RunState`,
  поэтому HUD показывает прохождение целиком, а не текущий уровень.
- `GAME OVER` / `WIN` остаются системным текстом по центру экрана.

## Враги

| Архетип | Поведение | Скорость |
|---|---|---|
| `walker` | патрулирует, разворачивается у стен и краёв | 130 / 150 px/s |
| `charger` | быстрый наземный, не сворачивает | 200 px/s |
| `flyer` | летит синусоидой, игнорирует гравитацию | 170 px/s |
| `spitter` | визуальный вариант walker; стрельба снарядом — будущая механика | 150 px/s |
| `witch` | визуальный вариант walker; фазы, телепорт и залпы — будущая механика | 150 px/s |

`walker` со скоростью 130 px/s — маркеры 1/2, остальные walker-варианты идут 150 px/s
(`sprite` 6 — `spitter`, 11/12 — `witch`). Новое поведение этих архетипов (снаряды, фазы
босса) — отдельная задача.

## Уровни

Восемь уровней, кривая сложности:

1. Лес — обучение: ходьба, прыжок, первые `walker`.
2. Опушка — прицел вверх/вниз, `flyer`.
3. Болото — узкие платформы.
4. Избушка — вертикальность, секреты.
5. Подпол — теснота, `charger`.
6. Склеп — ловушки, комбинированные враги.
7. Крипта — длинные перегоны, экономия патронов.
8. Зал ведьмы — финальный зал.

Целевая длина новой карты — 40–70 экранов по горизонтали, 3–6 секретов. Текущие уровни —
временные и заметно короче: эталоном длины они не являются.

Стартовый карман уровня 01 исправлен 2026-11-15: добавлена ступень `(8,34)` и `(9,32)` с
проходом на верх стены `(11,30)` — 1+2+2 тайла. Причина: `(7,32)` — потолок
(`blockUp`), а не платформа; спавн `(4,33)` был заперт (прогон бота S19). Прыжок не менялся.
