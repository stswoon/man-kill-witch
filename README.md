# Man Kill Witch

Ретро-платформер: охотник с дробовиком пробивается через проклятый лес, болото,
избушку и склеп ведьмы, чтобы вернуть брата.

PixiJS 8 + TypeScript, внутреннее разрешение **320×200**, целочисленный апскейл,
фиксированный шаг логики **1/70 с**.

## Статус

Ранний прототип. Графика, уровни и звук в `web/public/assets` — временные и будут
заменены оригинальными. Игровой код постепенно переводится на собственный формат
данных. Репозиторий остаётся приватным до завершения замены контента.

Дизайн и параметры ощущения — `docs/design.md`.

## Запуск

```bash
npm install
npm run dev        # сборка бандла + сервер на http://localhost:5173
npm run build      # только web/bundle.js
npm run typecheck  # tsc --noEmit
```

Управление: ←/→ ходьба, ↑/↓ прицел, Space прыжок, Ctrl выстрел, 1–8 — переключение уровня.

## Структура

| Путь | Что это |
|---|---|
| `web/src/game.ts` | игровая логика: физика, коллизии, враги, пули, двери, предметы, камера |
| `web/src/pixi-render.ts` | отрисовка: запекание уровня, спрайты, HUD, сообщения |
| `web/src/assets.ts` | константы, типы и загрузчики ассетов |
| `web/src/input.ts`, `sfx.ts` | клавиатура, синтезированные звуки |
| `web/src/main.ts` | состояния `title / play / gameover / win`, фиксированный шаг, отладка `window.mkw` |
| `web/public/assets/` | временные ассеты: тайлсет, уровни, атласы спрайтов |
| `tools/serve.mjs`, `tools/png.mjs` | статический сервер и запись PNG |
| `docs/design.md` | дизайн: правила, ощущение, враги, уровни |
