# Man Kill Witch

Ретро-платформер: могильщик **Сайлас Грив** идёт с дробовиком через проклятый лес, болото,
избушку и склеп к ведьме, укравшей имена с надгробий Холлоумира. Он идёт не за расплатой,
а чтобы закопать ведьму по всем правилам.

Phaser 4 + TypeScript, фиксированный шаг логики **1/70 с**. Имя, предыстория и облик героя —
[`docs/spec/04-hero.md`](docs/spec/04-hero.md).

Играбельный прототип: арт HD и финальный — титул `1920×1080`, тайлсет `80×80`, кадры героя и
врагов `120×160`, дверь `160×240`, HUD с bitmap-шрифтом ([`docs/spec/03-art.md`](docs/spec/03-art.md)).
Временными остаются данные уровней и звук. В репозитории только собственный код и
оригинальный арт.

## Запуск

```bash
npm install
npm run dev        # сборка в build/ + сервер на http://localhost:5173
```

Управление: ←/→ ходьба, ↑/↓ прицел, ↑ у двери — вход, Space прыжок, Ctrl выстрел, 1–8 — переключение уровня.

Остальное — в [`AGENTS.md`](AGENTS.md): команды (`build`, `test`, `test:e2e`, `typecheck`),
структура репозитория и правила. Дизайн и ощущение — [`docs/design.md`](docs/design.md),
спецификация — [`docs/spec/`](docs/spec/).
